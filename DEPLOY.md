## Проверяемая установка через SSH, когда доступ восстановлен

Указать подтверждённый путь; этот пример намеренно не подставляет непроверенный каталог:

```powershell
$env:PORTFOLIO_SSH_HOST = 'timeweb-lezard'
$env:PORTFOLIO_DOCUMENT_ROOT = '/home/c/cv038824/ПОДТВЕРЖДЕННЫЙ_КАТАЛОГ/public_html'
npm run deploy -- --dry-run
npm run deploy
```

Скрипт использует OpenSSH и локальную SSH-конфигурацию. Секреты не нужны в `.env`, репозитории или командной строке. Не зависит от файлов GNOSIS. `--dry-run` собирает и загружает релиз в приватный каталог, проверяет контрольные суммы и назначения, но не меняет публичные файлы.

Установщик запрещает каталог GNOSIS, symlink-пути, выходы за корень, посторонние имена, замену каталогов файлами и конфликт с `index.php`. Заменяет только `index.html` и файлы в двух собственных пространствах имён. Ничего не удаляет при успешной установке. Прежние версии файлов сохраняет в `../.portfolio-backups/`; `index.html` атомарно заменяется последним. При ошибке копирования восстанавливает уже затронутые файлы.

## Откат

Для ручной установки вернуть сохранённый `index.html` и при необходимости прежние файлы двух каталогов портфолио. Хешированные assets предыдущих сборок не удаляются.

Для управляемой установки использовать `receipt.json` в приватном backup: восстановить только перечисленные `replaced` файлы из этого backup. `created` содержит новые файлы портфолио; их можно оставить до отдельной проверенной очистки. Не копировать `receipt.json` в public_html. Другие приложения не затрагиваются.
