# WEB LIZARD / PORTFOLIO

Самостоятельное портфолио Ярослава: 10 полноэкранных сцен, реальные проекты, локальные WebP-скриншоты, портреты, галереи, карта компетенций и AI workflow.

Независимый проект в `D:\PYTHON\web-lizard-portfolio`, рядом с GNOSIS (`D:\PYTHON\Astroprocessor`). Собственная Git-история, сборка и deploy; зависимости от исходников GNOSIS нет.

## Запуск

Требуются Node.js 22.12+ (проверено на 24), npm. Python 3.10+ нужен для упаковки и deployment.

```powershell
npm ci
npm run dev
npm run build
npm run preview
```

## Архитектура

- `index.html` — семантические сцены и метаданные.
- `src/main.js` — hash routing, wheel/touch/keyboard, tabs, dialog gallery, Canvas и pointer tilt.
- `src/data.js` — проекты, тексты и технологии.
- `src/style.css` — композиция, responsive и reduced motion.
- `public/portfolio-media/` — оптимизированные фотографии и реальные скриншоты.
- `dist/` — независимая production-сборка (генерируется, не коммитится).
- `scripts/` — получение скриншотов, сборка ZIP, безопасная установка и проверки.

Нет backend, CDN и тяжёлого UI framework. Шрифты включены локально через Fontsource. Canvas 2D не требует WebGL и анимируется только во время перехода или движения указателя. Сцены плавно сменяются в обе стороны; Firefox использует отдельное направленное раскрытие для сохранения частоты кадров. Поддерживается `prefers-reduced-motion`.

Колесо/трекпад, свайп, стрелки, PageUp/PageDown, Space/Shift+Space, боковые индикаторы. Инерция одного жеста тачпада переключает не более одной сцены. На небольших экранах длинная сцена прокручивается внутри; переключение происходит у её края. Браузерные Back/Forward и прямые hash-ссылки работают. Алиасы `#projects`, `#eras`, `#archive`, `#workflow` поддержаны.

## Проверки

```powershell
npm test
npm run test:browser
```

Browser tests запускают production preview и используют установленный Microsoft Edge. Другой браузер можно выбрать через `PLAYWRIGHT_CHANNEL` в `playwright.config.js`/переменной окружения. Скриншоты тестов и отчёты лежат в игнорируемом `artifacts/`.

Все screenshots сняты непосредственно с открытых сайтов 13 октября 2026 года, сохранены локально и сжаты в WebP. У главных проектов есть кадры каталога/внутреннего интерфейса. Архивные изображения явно обозначены как текущий вид сайтов, а описание — как историческое участие. Современный Donstroy не используется как доказательство старого frontend: исторический screenshot не подтверждён.

Авторские портреты предоставлены владельцем. Цветовая стилизация и кадрирование выполняются CSS, лицо не генерировалось и не ретушировалось. Оригиналы фотографий в репозиторий не включены.
